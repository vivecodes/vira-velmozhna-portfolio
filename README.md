# Vira Velmozhna - portfolio

Personal site of [Vira Velmozhna](https://viravelmozhna.dev), a frontend developer based in Hanover, Germany.

It presents experience, skills, education, and selected projects in English and German, with downloadable CVs for both languages. The design uses a dark, editor-inspired look - sticky “IDE” chrome, commit-style experience, and a compact projects list.

Built with [Astro](https://astro.build) as a static site.
